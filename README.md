# Inventory, Equipment & Crafting System: playable demo

Play the demo of **Inventory, Equipment & Crafting System**, an Unreal Engine plugin by heyheythere, before you buy it.

## Download

- [Latest release](../../releases/latest): `InventoryDemo-Win64.zip`, for Windows 10 or 11, 64-bit.
- Unzip it anywhere and run `InventoryDemo.exe`.
- The demo shows the plugin's version 1.0.0, the same one sold on Fab.

## Controls

| Action | Keyboard and mouse | Gamepad |
|---|---|---|
| Move | W A S D | Left stick |
| Look | Mouse | Right stick |
| Jump | Space | A |
| Run | Shift, held | Left stick click, held |
| Inventory | Tab | View |
| Pick up, open, trade | E | X |
| Hotbar | 1 to 0 | D-pad left, right |
| Eat or drink from it |  | D-pad up |
| Move an item | Drag | A |
| Split, rotate, drop | Ctrl-drag, R, X | LT, RT, L3 |
| Use, equip | Right-click | X |
| Move across, sell | Shift-click | Y |
| Bag, crafting | Q, E | LB, RB |
| Controls card | I | D-pad down |
| Guide | G | Y |
| Save, load | F5, F9 |  |
| Start over | R, twice | Menu, twice |
| Pause | Esc |  |
